# 1.4.0

- New: Connect Tools. Allows creating networks that connect a start and end node. 
- Connect Tool: Added simple curve mode. Loop mode and complex curve are still work in progress.
- Connect Tool/SimpleCurve: More smartly create initial bezier control point positions based on start/end direction.
- Generate Tool: Added option to follow the terrain and rewrote elevation handling. All generate modes should now allow for fine-tuned precision on elevation and terrain handling.
- Translations: Updated translations across the board. Thank you volunteers!
- UI: Added close button to tool panel
- Tooltips: Fixed bug that would keep stale tooltips without clearing them
- Internal: Added UIL as dependency
- Internal: Removed some dead code
