# 1.6.0

- New: Tunnel mode for the Connect, Slope and Parallel tools. Switch it on and the road goes underground where it meets higher ground, with each tunnel mouth placed where the hill is deep enough for a clean, straight entrance.
- New: Connect and Parallel start with the network you have selected, and each Parallel section keeps its own. The other tools start with the last network you picked.
- Fix (Slope tool): the preview now shows the road at the heights the tool will build, where it used to show it as a bridge.
- Fix (Slope tool): when a side road leaves the sloped road and joins it again further along, both of its ends now follow the new slope. Before, one end stayed at the old height, detached from the road.
- Fix (Connect tool): leaving the tool with two nodes picked but not connected, then reopening it later from the panel, would crash the game at the next save (your saves are safe, it happened before anything was written)
- Fix minor styling issues
- Minor cleanup and refactoring
